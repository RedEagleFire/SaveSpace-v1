SaveSpace voor Windows (64-bit)
===============================

1. Pak dit ZIP-bestand uit in een map.
2. Start SaveSpace.exe.

SaveSpace bevat de .NET 10-runtime. Je hoeft de .NET SDK of .NET-runtime niet
apart te installeren.

De ingebouwde browser en documentvoorbeelden vereisen de Microsoft Edge
WebView2 Runtime. Die is al aanwezig op de meeste bijgewerkte Windows-
installaties. Als SaveSpace meldt dat WebView2 niet beschikbaar is, start dan
WebView2RuntimeInstaller.exe met een internetverbinding en herstart SaveSpace.
Dit officiële installatieprogramma van Microsoft downloadt de runtime. Als
Windows om beheerdersgoedkeuring vraagt, vraag dan je beheerder om de runtime
te installeren.

Vereist: Windows 10/11, x64.
Download de nieuwste versie:
https://github.com/RedEagleFire/SaveSpace-v1/releases
WebView2-informatie: https://developer.microsoft.com/microsoft-edge/webview2/
